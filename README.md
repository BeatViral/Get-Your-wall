# GET YOUR WALL

**Your brand. Your people. Your Wall.** A polished concept demo for branded, independent social communities.

## Run locally

`npm install` then `npm run dev`

## Production build

`npm run build`

## GitHub Pages

Push the `main` branch, then enable **GitHub Actions** as the Pages source in the repository settings. The included workflow builds and deploys `dist` automatically. The app uses hash-based URLs so Wall links also work on refresh.
